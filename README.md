# SkillPi

**Find skills — safely.**

`find-skills` made you browse. SkillPi scouts for you: describe the job — "grow my TikTok", "automate my store's content", "audit this repo" — and it searches SkillPi and the open registries, vets every candidate for safety, permissions and freshness, and hands you the best picks with install commands and one clear recommendation.

## Why SkillPi

- One command, any skill — you describe an outcome, not a keyword
- Vetted, not just listed — permission checks on every pick; credential-grabbing skills get flagged, not recommended
- Curated picks first — security-scanned skills and scenario bundles (TikTok Creator Pack, Indie Store Seller Pack…) surface first when they fit
- Free forever — discovery should be free; that's the whole point

## Install

With the skills CLI:

    npx skills add skillpi/skillpi

Or manually — clone this repo into your agent's skills directory:

    git clone https://github.com/skillpi/skillpi ~/.claude/skills/skillpi

## Use it

Just tell your agent what you're trying to do:

> "SkillPi, find me something that turns my product photos into TikTok posts."
> "Is there a skill that audits a landing page for conversion?"
> "Find me a skill that drafts replies to customer emails."

## About

SkillPi is the free discovery skill from SkillPi (https://skillpi.com) — one marketplace, infinite skills. Every skill sold on SkillPi passes a security scan and declares its permissions on the product page, because in an ecosystem where ~12% of open-registry skills have been caught behaving maliciously, trust is the product.
